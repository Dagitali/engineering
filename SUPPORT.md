# Support

- [Support Boundary](#support-boundary)
- [Where to Get Help](#where-to-get-help)

- [Maintenance Expectations](#maintenance-expectations)

## Support Boundary

This repository provides engineering guidance and blank templates. It does not operate consuming
products or guarantee that copied instructions match a project's current tools or contracts.
Identify the adopted commit or tag when requesting help; review changes before updating a copy.

## Where to Get Help

Start with the [README] and [contributor guide]. Use available repository issues or pull requests
for sanitized documentation corrections and adoption questions. Follow the [security policy] for
suspected vulnerabilities and the [Code of Conduct] for conduct concerns.

## What to Include

Provide the document path and section, repository revision, expected and observed guidance, and a
minimal sanitized example. For validation failures, include the tool version, exact command, and
relevant diagnostics. Omit credentials, private project content, and personal information.

## Maintenance Expectations

No response deadline, backport period, or long-term support window is established here. Consumers
own validation and maintenance of adopted copies. The [release policy] describes compatibility
review and release records; project-specific support remains with the consuming project.
