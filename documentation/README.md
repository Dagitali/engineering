# Documentation Guidance

- [Document Scope](#document-scope)
- [Start Here](#start-here)
- [Validate Documentation](#validate-documentation)
- [Related Guidance](#related-guidance)

## Document Scope

Maintain reusable practices and blank templates here. Product-specific contracts, completed records,
and private evidence belong with their owners. This collection’s own release history stays in its
[release archive].

## Start Here

Read the [repository overview] and [contributor guide]. Use [maintenance guidance] to locate
canonical evidence and update related claims. Try the [adoption tutorial] for a disposable example.

## Validate Documentation

Follow the [validation procedure]. Check destinations, anchors, reference labels, definition
sorting, source accuracy, and blank placeholders. Local checks do not verify external availability
or hosted enforcement.

## Related Guidance

Use the [template index] for reusable forms, [architecture index] for decision recording, and
[release policy] for changes to this repository.
